## ⭐ Featured Projects

### 🎬 [Movie Recommendation System](https://github.com/Billawan12/day5-recsys)
A recommendation engine using **Matrix Factorization (SVD)** with content-based fallback for cold-start problems. Built with FastAPI and Docker.
- **Tech**: Python, FastAPI, Docker, scikit-learn
- **What it shows**: ML + product thinking + real-world recommendation logic

### 📈 [Churn Classifier (Enterprise-Grade)](https://github.com/Billawan12/day2-churn-classifier)
Enterprise-style customer churn prediction system with **SMOTE**, **SHAP explainability**, and a production-ready API.
- **Tech**: Python, Random Forest, SMOTE, SHAP, FastAPI
- **What it shows**: Strong ML fundamentals + business problem solving

### 🏠 [House Price Predictor](https://github.com/Billawan12/day1-pricing-predictor)
End-to-end ML pipeline for predicting California house prices using **PyTorch** and FastAPI.
- **Tech**: Python, PyTorch, FastAPI, Docker
- **What it shows**: Full ML workflow from data to deployment

### 📱 [Expense Tracker](https://github.com/Billawan12/expense-tracker)
Full-stack expense management application with a modern frontend and backend workflow.
- **Tech**: Spring Boot, React, TypeScript, PostgreSQL
- **What it shows**: Full-stack engineering capability

### 🚨 [Emergency Dispatch System](https://github.com/Billawan12/emergency-dispatch-system)
A system built to support emergency response coordination and resource allocation.
- **Tech**: Python, Systems Design
- **What it shows**: Problem solving in critical real-world scenarios

### 🔐 [Fake News Detector](https://github.com/Billawan12/fake-news-detector)
Machine learning system for fake news detection using **TF-IDF** and a **Passive Aggressive Classifier**.
- **Tech**: Python, scikit-learn
- **What it shows**: NLP + classification + strong model evaluation

### 📡 [Real-Time Financial Data Pipeline](https://github.com/Billawan12/tiger-cloud-realtime-financial-pipeline)
A live financial data ingestion and analytics pipeline built with Python, PostgreSQL, and TimescaleDB.
- **Tech**: Python, PostgreSQL, TimescaleDB, Cloud
- **What it shows**: Data engineering + time-series processing

### 🌍 [SuddWatch](https://github.com/Billawan12/suddwatch)
